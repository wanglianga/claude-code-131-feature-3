# 悦安月子中心 · 产妇护理计划与家属探访平台

月子中心业务一体化平台：覆盖**入住登记 → 护理计划执行 → 多角色协同异常处置 → 家属探访/授权查看 → 套餐提前退所结算（核对/冻结/护理确认/家属同步/财务复核）→ 出所后随访与复购转介绍**全流程。所有角色（护理师、护士长、儿科医生、营养师、产康师、月嫂、前台、财务、家属、中心管理者）围绕**同一间房**协同工作。

## 技术栈

- **Next.js 15（App Router, TypeScript）**：服务端渲染页面 + API 路由（前后端一体）
- **数据库**：Node 22 内置 `node:sqlite`（文件库 `data/mcare.db`，首次启动自动建表+播种演示数据；老库启动时自动平滑加列迁移）。SQL 均为标准语法，表结构可直接迁移到 MySQL（将 `datetime('now','localtime')` 默认值替换为 `CURRENT_TIMESTAMP` 即可）
- **认证**：HMAC 签名 httpOnly Cookie 会话，SHA-256 加盐口令哈希
- 无外部服务依赖，克隆后安装依赖即可运行

## 本地启动

### 方式一：npm（Node.js ≥ 22.5）

```bash
npm install        # 安装依赖
npm run dev        # 开发模式 http://localhost:3000
# 或生产模式：
npm run build && npm start
```

### 方式二：Docker / Docker Compose（一键启动）

```bash
docker compose up --build -d     # 构建并后台启动，访问 http://localhost:3000
docker compose logs -f           # 查看日志
docker compose down              # 停止
```

SQLite 数据持久化在宿主机 `./data` 目录（首次启动自动建表+写入演示数据）。Linux 宿主若遇目录权限问题，先执行：

```bash
mkdir -p data && sudo chown -R 1000:1000 data
```

也可直接使用 Dockerfile：`docker build -t mooncare-platform . && docker run -p 3000:3000 -v "$PWD/data:/app/data" mooncare-platform`。

> 重置演示数据：删除 `data/` 目录（Docker 方式为 `sudo rm -rf ./data`）后重启即可。

## 套餐提前退所结算（本版核心流程）

产妇因家庭原因提前退所时，按以下多角色协同流程办理，避免**费用和服务记录脱节**：

1. **财务发起核对（`refund_plans.create`）**：平台自动核对 **已住天数**（套餐日均价×已住天）、**已执行产康项目**（产康排班已完成次数×单次成本）、**餐食成本**（已供餐天数×日成本）、**赠送服务**（已发放赠品折算，未发放随退所核销不收费）、**押金**（原路退还）与已登记增项；可手工录入其他扣减/减免。生成退款方案（应退=押金+套餐款−已消费合计±调整）。
2. **冻结套餐尾款**：方案一生成即冻结该房套餐尾款——冻结期禁止追加费用、费用作废、套餐升级、直接确认结算（接口与房间360视图均拦截）。
3. **护理主管确认护理动作（`care.verify`）**：护士长在工作台逐房核对已完成/待执行护理任务数、护理记录条数、未结质疑、已执行产康次数与已供餐天数，确认费用口径与服务记录一致；核对同时**同步生成出所回访**（退所后第3天）与母婴随访（第30天）。未核对前财务不能把方案同步家属。
4. **退款方案同步家属端（`refund_plans.confirm`）**：财务一键同步，家属端可见完整退款明细与冻结提示，可**知悉确认**或**提出异议**；异议自动生成"退所争议"异常工单并同步护士长，处理后重新同步。
5. **财务复核退款（`refund_plans.review`）**：家属无异议（或异议已处理）且已知悉后，财务复核：生成退款流水（应退为负时生成应补款）、结算单直接确认、办理出所并释放房间、关闭提前退所工单、家属端收到复核结果通知。

种子数据中 **901 房刘敏**正处于该流程第 2→3 步（家庭原因提前 3 天退所，财务已核对应退 ¥11,311 并冻结尾款，等待护士长核对护理动作），登录后可直接演练。

- 旧的"直接办理提前退所"入口被引导到退款方案流程；
- 发起退款方案自动核对天数/产康/餐食/赠品/押金并冻结套餐尾款；
- 冻结期追加费用、直接确认结算均被拒绝；护理主管未核对时同步家属被拒绝；
- 护士长核对护理动作后自动生成出所回访；同步前家属端不可见方案；
- 方案同步家属端后家属可提异议（异议未处理禁止复核）→ 护士长处理异议 → 重新同步 → 家属知悉；

- 种子 901 房方案的护理核对与家属同步演练，且复核前房间保持在住。

## 功能地图（需求 → 实现）

- **入住档案**：分娩方式、产后天数、过敏史、哺乳方式、宝宝体重、黄疸观察、房型套餐、餐食禁忌、家属探访权限、医生建议（前台入住登记表单，自动建护理计划/赠品/费用/家属账号）
- **护理安排**：查房、伤口观察、乳房护理、产康课程、月子餐、宝宝洗澡抚触、夜间照护（护理计划+每日任务，护士长可增改）
- **家属端**：经授权的护理摘要（仅可见标记记录）、探访预约（含临时探访）、费用明细、**提前退所退款方案同步/知悉/异议**、意见反馈、随访安排、与中心留言
- **提前退所结算**：已住天数/已执行产康/餐食成本/赠送服务/押金五项核对 → 冻结套餐尾款 → 护理主管确认护理动作（出所回访同步生成）→ 退款方案同步家属 → 家属知悉/异议 → 财务复核退款出所（退款流水+已确认结算单+工单关闭+家属通知）
- **异常协同**（围绕同一间房，工单+时间线+角色路由）：黄疸升高→儿科；乳腺堵塞/记录质疑/退所争议/退款异议→护士长；临时探访→前台；月嫂请假→护士长改派；餐食忌口→营养师（配餐自动核对）；产康延期→产康师；套餐升级/提前退所→费用核对+工单
- **出所后**：护理计划与异常记录留存、费用结算单、出所回访/母婴随访计划（提前退所由护理主管核对时自动安排）、复购与转介绍线索
- **其他**：套餐赠品发放、产康师排班、宝宝托管日志、探访消毒登记、房间升级（自动换房+补差价）、医生巡诊记录
- **管理者**：按房间聚合护理动作、家属沟通、费用变化、异常处置；高敏感客诉区（记录质疑/退所争议/忌口异常/低分反馈）；口碑均分
- **反馈联动**：家属反馈可被护士长标记"影响护理师排班"，低分反馈进入管理看板；护理记录进入出所后母婴随访；退所争议自动同步护士长
