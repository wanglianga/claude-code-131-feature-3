# 悦安月子中心 · 产妇护理计划与家属探访平台

月子中心业务一体化平台：覆盖**入住登记 → 护理计划执行 → 多角色协同异常处置 → 家属探访/授权查看 → 出所结算 → 出所后随访与复购转介绍**全流程。所有角色（护理师、护士长、儿科医生、营养师、产康师、月嫂、前台、财务、家属、中心管理者）围绕**同一间房**协同工作。

## 技术栈

- **Next.js 15（App Router, TypeScript）**：服务端渲染页面 + API 路由（前后端一体）
- **数据库**：Node 22 内置 `node:sqlite`（文件库 `data/mcare.db`，首次启动自动建表+播种演示数据）。SQL 均为标准语法，表结构可直接迁移到 MySQL（将 `datetime('now','localtime')` 默认值替换为 `CURRENT_TIMESTAMP` 即可）
- **认证**：HMAC 签名 httpOnly Cookie 会话，SHA-256 加盐口令哈希
- 无外部服务依赖，克隆后安装依赖即可运行

## 本地启动

### 方式一：Docker 一键启动（推荐）

```bash
docker compose up --build     # 构建并启动，访问 http://localhost:3000
```

数据通过命名卷 `mcare-data` 持久化到容器内 `/app/data`；生产环境请通过环境变量 `MCARE_SECRET` 覆盖会话密钥。停止用 `docker compose down`（加 `-v` 会同时删除数据卷、重置演示数据）。

### 方式二：本机 Node 启动

```bash
npm install        # 安装依赖（Node.js ≥ 22.5，需内置 node:sqlite）
npm run dev        # 开发模式 http://localhost:3000
# 或生产模式：
npm run build && npm start
```

首次启动自动创建 `data/` 并写入演示数据（含在住订单 2 个、已出所订单 1 个、各角色账号）。删除 `data/` 目录即可重置为初始演示数据。

### 手工验证路径建议

1. `admin` 登录 → 看板按房间显示护理动作/费用变化/异常数 → 点入 801 房间360视图，查看异常工单处置时间线与房间动态
2. `nutrition` 登录 → 登记含"虾仁"的晚餐 → 自动命中 801 忌口（海鲜）并生成异常 → `headnurse` 异常中心受理/解决
3. `family1` 登录 → 预约临时探访 → `front` 审核批准并做消毒登记 → 家属端看到状态与消毒记录
4. `family1` 对夜间照护记录点"质疑" → `headnurse` 工作台"退所争议/质疑"出现该工单
5. `finance` 登录 → 对 801 登记增项费用 → 家属端费用明细同步可见
6. **套餐提前退所结算（本次新增主线）**：`front`/`finance` 在某在住订单（如 901）房间视图选择实际退所日期、填写"家庭原因"→提交申请
   1. 系统完成**平台核对**：已住天数、已执行产康项目、餐食成本、已发赠品、押金，生成草稿退款方案、提前退所异常工单（同步护士长）、出所回访/母婴随访同步生成；
   2. `finance` 在财务工作台**生成退款方案**（可手工调整金额）→ 确认前**冻结套餐尾款**（结算单显示冻结额，期间不可确认结算）；
   3. `headnurse` 工作台出现"提前退所待护理核对"→**逐项确认已完成护理动作**（护理任务/记录批量核对；有家属质疑记录时须先核实），避免费用与服务记录脱节；
   4. 财务/护士长/前台将**退款方案同步家属端** → `family` 家属端费用区出现只读退款方案（核对明细+应退合计+六步进度）；
   5. `finance` **财务复核退款**：通过则生成退款流水、确认结算单、正式办理出所（异常工单自动办结）；驳回则解冻尾款、可重新核算。
7. 正常到期出所：在房间视图选择不早于预计出所的日期办理，直接生成结算草稿，财务确认即可（不走退款冻结流程）。

## 功能地图（需求 → 实现）

- **入住档案**：分娩方式、产后天数、过敏史、哺乳方式、宝宝体重、黄疸观察、房型套餐、餐食禁忌、家属探访权限、医生建议（前台入住登记表单，自动建护理计划/赠品/费用/家属账号）
- **护理安排**：查房、伤口观察、乳房护理、产康课程、月子餐、宝宝洗澡抚触、夜间照护（护理计划+每日任务，护士长可增改）
- **家属端**：经授权的护理摘要（仅可见标记记录）、探访预约（含临时探访）、费用明细、意见反馈、随访安排、与中心留言
- **异常协同**（围绕同一间房，工单+时间线+角色路由）：黄疸升高→儿科；乳腺堵塞/记录质疑/退所争议→护士长；临时探访→前台；月嫂请假→护士长改派；餐食忌口→营养师（配餐自动核对）；产康延期→产康师；套餐升级→费用折算+工单
- **套餐提前退所结算**（分阶段、多角色）：①平台核对（已住天数/已执行产康/餐食成本/赠品/押金快照）→ ②财务生成退款方案（可手工调整）并在确认前**冻结套餐尾款**（结算单联动锁定）→ ③护士长**核对已完成护理动作**（任务/记录批量确认，质疑记录须先核实，避免费用与服务记录脱节）→ ④**退款方案同步家属端**（只读明细+应退+六步进度，同步前家属不可见）→ ⑤**财务复核退款**（通过才生成退款流水、确认结算、正式出所，出所回访同步生成；驳回则解冻重算）
- **出所后**：护理计划与异常记录留存、费用结算单（含尾款冻结/应退展示）、回访/母婴随访计划（提前退所自动生成"出所回访"）、复购与转介绍线索
- **其他**：套餐赠品发放、产康师排班、宝宝托管日志、探访消毒登记、房间升级（自动换房+补差价）、医生巡诊记录
- **管理者**：按房间聚合护理动作、家属沟通、费用变化、异常处置；高敏感客诉区（记录质疑/退所争议/忌口异常/低分反馈）；口碑均分
- **反馈联动**：家属反馈可被护士长标记"影响护理师排班"，低分反馈进入管理看板；护理记录进入出所后母婴随访；退所争议自动同步护士长
